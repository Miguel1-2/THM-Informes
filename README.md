# THM-Informes

Este repositorio contiene informes de máquinas de **TryHackMe (THM)**, creadas para practicar diferentes técnicas de reconocimiento, enumeración y explotación dentro de entornos controlados.

A través de estos laboratorios podemos identificar situaciones como comentarios en el código fuente que divulgan información, malas configuraciones en servidores, vulnerabilidades de control de acceso, escalada de privilegios, reverse shells, IDOR y otros problemas de seguridad.

##  Objetivo

El objetivo de estos informes es mejorar mis conocimientos y habilidades en **ciberseguridad y seguridad ofensiva**, aprendiendo a identificar vulnerabilidades y malas configuraciones de forma cada vez más rápida y comprender cómo pueden ser aprovechadas por un atacante.

También busco documentar cada proceso para poder utilizar estos conocimientos como referencia en futuras prácticas.

## Importancia de la seguridad

- En ciberseguridad, los pequeños detalles pueden marcar una gran diferencia.

- Una configuración que parece poco importante, un comentario olvidado en el código fuente o un permiso asignado incorrectamente pueden terminar exponiendo información sensible o permitiendo un acceso no autorizado.

- Por este motivo, es importante implementar medidas de seguridad adecuadas para proteger los datos sensibles de **clientes y empleados**, así como la reputación y los sistemas de una organización.

> **Nota:** Todos los procedimientos documentados en este repositorio se realizan con fines educativos y dentro de entornos autorizados de TryHackMe.
